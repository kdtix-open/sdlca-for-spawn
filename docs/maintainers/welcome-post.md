# Welcome post for Discussions

This page is for the maintainers. It holds the text of the first post in [Discussions](https://github.com/kdtix-open/sdlca-for-spawn/discussions), so that a person can read and change it before it goes public. The project's AI policy says an agent never posts for a person, so post it by hand: open Discussions, choose New discussion, pick the Announcements category, paste the text below, post it and pin it. A drafting tool wrote it, so read every sentence and make it yours first.

The same goes for the starter issues: `scripts/seed-starter-issues.py` prints them (a dry run) and posts them only when you run it with `--apply`. See [GitHub settings for maintainers](github-settings.md).

## The text

```markdown
Welcome, and thank you for stopping by.

The SDLCA agent kit is an open-source (Apache-2.0) set of small tools that lets you direct an AI coding agent on [Spawn](https://www.spawn.co) by chatting with it. It is an **unofficial community project**: it is made by KDTIX Open, and it is not affiliated with, endorsed by or supported by Spawn. Everything it does goes through Spawn's published doors, with your own account.

It is early software. The first release (0.1.0) has not been cut yet, and the [roadmap](https://github.com/kdtix-open/sdlca-for-spawn/blob/main/docs/community/roadmap.md) says plainly what works today and what is only planned.

**You are welcome here, whoever you are.** You do not need to be a programmer. Trying the [quick start](https://github.com/kdtix-open/sdlca-for-spawn/blob/main/docs/getting-started.md) and telling us where you got stuck is a real contribution.

Some ways to join in:

- **Ask a question** in the Q&A category. No question is too small.
- **Share an idea** in Ideas, even a half-formed one.
- **Show what you built** in Show and tell.
- **Pick a first issue**: look for [good first issue](https://github.com/kdtix-open/sdlca-for-spawn/labels/good%20first%20issue) and [help wanted](https://github.com/kdtix-open/sdlca-for-spawn/labels/help%20wanted). Many have a mentor ready to help.
- **Read the [contributing guide](https://github.com/kdtix-open/sdlca-for-spawn/blob/main/CONTRIBUTING.md)** and the [Code of Conduct](https://github.com/kdtix-open/sdlca-for-spawn/blob/main/CODE_OF_CONDUCT.md). We want this to be a kind place.

If you come from the Spawn community: we are an outside project and we would like to hear how the kit can fit Spawn's rules and your worlds better. Problems with Spawn itself (a world, a player, the website) belong with [Spawn's own support](https://www.spawn.co/support), and anything you send to Spawn is covered by Spawn's terms, not ours. Please never post a token, an invite code or anyone's private messages anywhere here.

We aim to reply within about a week. This is a small team, so thank you for your patience, and thank you for being here.
```
